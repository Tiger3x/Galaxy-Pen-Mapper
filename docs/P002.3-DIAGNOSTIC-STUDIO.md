# P002.3/P002.4 — Galaxy Pen Diagnostic Studio

## Objective
Refactor the monitor into a real diagnostic application before P003.

## Requirements

- Restore Windows Pointer capture
- Restore Raw HID capture
- Keep session labels
- Keep CSV export
- Add professional live UI
- Separate UI, input capture and export layers

## Architecture

```
src/
  ui/
    MainWindow
  input/
    PointerCapture
    RawHidCapture
  capture/
    Session
    CsvWriter
```

## Implementação

- `ui/MainWindow` coordena a interface e as regras de escopo da captura;
- `ui/DiagnosticPanel` renderiza o painel de diagnóstico e a área de teste;
- `input/PenCapture` lê `WM_POINTER` e `GetPointerPenInfo`;
- `input/RawHidCapture` registra e lê relatórios Digitizer Raw HID;
- `capture/SessionWriter` grava CSV UTF-8 com rótulo, descrição, eventos de ponteiro e relatórios Raw HID.

Os eventos de caneta só são exportados quando a sessão está ativa, a janela está em primeiro plano e a caneta está dentro da área de teste. A partir da P002.4, botões de mouse, teclado e comandos interpretados continuam sendo exportados enquanto a sessão e a janela permanecem ativas, permitindo observar ações que fazem o ponteiro da caneta desaparecer temporariamente. A validação de compilação e em hardware requer uma instalação local das ferramentas C++ para Windows.
