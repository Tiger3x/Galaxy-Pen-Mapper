# P002.3–P002.5 — Galaxy Pen Diagnostic Studio

## Objective
Refactor the monitor into a real diagnostic application before P003.

## Requirements

- Restore Windows Pointer capture
- Restore Raw HID capture
- Keep session labels
- Keep CSV export
- Add professional live UI
- Separate UI, input capture and export layers

## Architecture

```
src/
  ui/
    MainWindow
  input/
    PointerCapture
    RawHidCapture
  capture/
    Session
    CsvWriter
```

## Implementação

- `ui/MainWindow` coordena a interface e as regras de escopo da captura;
- `ui/DiagnosticPanel` renderiza o painel de diagnóstico e a área de teste;
- `input/PenCapture` lê `WM_POINTER` e `GetPointerPenInfo`;
- `input/RawHidCapture` registra e lê relatórios Digitizer Raw HID;
- `capture/SessionWriter` grava CSV UTF-8 com rótulo, descrição, eventos de ponteiro e relatórios Raw HID.

Os eventos de ponteiro da caneta só são exportados quando a sessão está ativa, a janela está em primeiro plano e a caneta está dentro da área de teste. A partir da P002.4, botões de mouse, teclado e comandos interpretados continuam sendo exportados enquanto a sessão e a janela permanecem ativas, permitindo observar ações que fazem o ponteiro da caneta desaparecer temporariamente.

Na P002.5, os relatórios Raw HID do digitizador são registrados durante toda a sessão, mesmo se a janela perder o foco; os canais de mouse e teclado continuam restritos ao primeiro plano. O CSV inclui `FOREGROUND_SAMPLE` aproximadamente a cada 50 ms, `window_foreground` (`1` ou `0`) em cada evento Raw Input e `raw_input_code` (`0` = primeiro plano; `1` = entrada de segundo plano). Os horários têm precisão de milissegundos. Isso permite verificar se uma lacuna durante os botões da PW500 coincide com perda de foco; não mede diretamente o sinal EMR da caneta. A compilação foi validada localmente; a confirmação com a PW500 na tela ainda depende das capturas do usuário.
